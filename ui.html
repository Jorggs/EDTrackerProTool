Receiver mode takes head data from this tool in Tracker mode on another PC, or from OpenTrack's "UDP over network" output, so you don't need OpenTrack here. Windows may ask to allow this tool through the firewall the first time: allow it on private networks (Tailscale counts as one). Recentre here (button or hotkey) asks the sending PC to recentre the tracker itself, so offsets never build up. If the sender is OpenTrack or an older version of this tool, it recentres the received data here instead. Recentre on the sending PC also works.

vJoy presents yaw, pitch and roll as a virtual joystick (±180° across each axis, the same scaling as the EDTracker's own joystick). In Elite, bind head look to the vJoy axes. Use either vJoy or FreeTrack/TrackIR for Elite, not both. The vJoy device must have the chosen axes enabled in "Configure vJoy".

FreeTrack / TrackIR publishes the angles the same way OpenTrack does, so games with TrackIR support on this PC (Elite Dangerous included) pick it up as head tracking.

UDP over network sends the same data as OpenTrack's "UDP over network" output: six numbers per update, about 60 times a second. On the other machine (a Shadow PC over Tailscale, say), run OpenTrack with input UDP over network on the same port and output freetrack 2.0 Enhanced. Use that machine's Tailscale address (100.x.x.x) or its MagicDNS name. Allow OpenTrack through the Windows firewall there.

The invert options apply to both outputs. Recentre (button or hotkey) resets the tracker itself, so it works from here even while you're in the remote session.

In Elite: remove the joystick axes bound to head look, so the tracker isn't read twice, and make sure head tracking is enabled in the controls. Start this tool before the game.

Don't run OpenTrack's FreeTrack output at the same time; they use the same channel. The client DLLs are OpenTrack's (ISC licence), copied to %LOCALAPPDATA%\EDTrackerProTool\ftclient.
